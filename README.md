# 🍮 Humanfall P2P

휴먼 폴 플랫 스타일의 말랑말랑 3D 파티 게임 + **서버 없는 P2P 멀티플레이**.
베이스: [nhaouari/stickfight](https://github.com/nhaouari/stickfight) (Three.js + 커스텀 고정스텝 엔진 구조를 차용)

## 플레이

| 조작 | 키 |
|---|---|
| 이동 | `WASD` |
| 점프 | `Space` |
| 달리기 | `Shift` |
| 왼손/오른손 잡기 | 마우스 `좌클릭` / `우클릭` (토글, 켜두면 닿자마자 잡힘) |
| 양손 동시 잡기 | `E` / 휠클릭 (토글) |
| 시점 | 마우스 (클릭해서 잠금) · 방향키도 가능 |
| 줌 | 휠 |
| 까꿍 | `T` |
| 📱 이동 | 왼쪽 가상 조이스틱 (끝까지 밀면 달리기) |
| 📱 시점 / 잡기 / 점프 | 오른쪽 드래그 / 🤏L·R🤏·🤲 버튼(토글) / ⬆️ 버튼 |

- 📦 박스·공을 **잡고 들고 던지기**, 친구를 **붙잡고 질질 끌기** (잡히면 조작 반감!)
- 🏋️ **무게 시스템**: 가까이서 잡고 **위를 보면 번쩍**. 가벼운 상자 한 손, 공은 양손, 특대 상자는 못 들고 끄는 것만. 번쩍 들면 휘청
- 🧗 **벽·모서리 잡고 매달린 뒤 아래를 보면 풀업 등반**. 상자 위에도 올라설 수 있음
- 😈 **지옥 점프맵**: 외나무다리 → 무빙 발판 → 점프대 → 하늘 정밀 발판, 🚩 체크포인트에서 부활
- 🏆 빛나는 **골인 링**에 들어가면 1점 + 리스폰
- 🕳️ 떨어지면 체크포인트(또는 스폰)로 복귀

잡기 물리는 [HL2 그래비티건 shadow controller](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/game/server/hl2/weapon_physcannon.cpp)식 임계감쇠(4.5Hz) + 손 힘 상한 + 질량별 최대 추종속도를 따릅니다.

## P2P 멀티플레이 (서버 불필요)

[Trystero](https://github.com/dmotz/trystero) torrent 전략 = 공개 WebTorrent 트래커를 통한 WebRTC 시그널링.
서버를 둘 필요 없이 **방 코드 6자리**만 공유하면 연결됩니다. 직접 연결(WebRTC)이 안 되면 **중계 모드**(릴레이 경유)로 자동 전환됩니다.
직접 연결(WebRTC)이 안 되는 네트워크에서는 20초 후 **중계 모드**(공개 릴레이 경유, 8Hz)로 자동 전환됩니다.

1. `새 방 만들기` → 생성된 코드 확인 (클릭하면 복사)
2. 친구에게 코드 전달 → 친구는 코드 입력 후 `참가하기`
3. 최대 인원 제한 없음 (4명 권장), 15Hz 상태 동기화 + 소유권 기반 프롭 동기화

> V1 한계: 프롭 물리 소유권은 마지막으로 잡은/민 사람에게 있으며,
> 친구를 잡는 건 로컬에서만 끌려가는 연출입니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 프로덕션 빌드
```

## 구조 (stickfight 차용)

```
src/
  core/    Engine(60Hz 고정스텝) · Input(버퍼드 점프) · EventBus · Config
  human/   HumanFactory(절차적 말랑 휴먼, 에셋 없음) · HumanSystem(물리+잡기+등반)
  world/   떠있는 섬 레벨 · 커스텀 경량 물리 · 프롭(크레이트/공) · 골인 링
  camera/  3인칭 추적 카메라
  net/     Trystero P2P 룸 · 15Hz 상태/10Hz 프롭 동기화 · 리모트 보간
  ui/      메뉴(닉네임/방코드) · HUD · 토스트
  audio/   WebAudio 미니 신스 효과음
```
